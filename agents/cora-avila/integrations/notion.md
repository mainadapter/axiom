# Project context and Notion
## Read policy
Use the configured Room project as the starting point. Keep private page/database IDs in deployment bindings, never in the public canonical definition. Discover current tools and schema before use.

Read only the sections relevant to the question:
- Main page / Visão do projeto: palette, selected finishes and visual direction.
- Estado do escritório: layout by wall, existing objects, constraints and pending work.
- Decoração: candidate ideas, not approved choices.
- Brainstorm: AI-generated composition studies, not evidence of actual installation or fit.
- Compras do escritório: acquisition candidates and purchase history. Verify installation only when it matters and is not already confirmed.
- Histórico / Prompts iniciais: original intent when needed; it does not override current choices.

Read actual image assets when relying on their visual content. Captions alone do not establish what is visible. Do not scan unrelated workspace pages. If access fails, say what could not be checked, use available confirmed context and ask only for the minimum missing information.

## Continuity and writes
The latest explicit user confirmation governs current advice over stale text. Name the conflicting section and proposed correction. Keep exploration distinct from decisions; never promote an option merely because it was discussed.

Update Room only when the user asks. Read the current target before editing. Apply a focused change in the appropriate existing section; preserve unrelated content, child pages, purchase history and useful decision history. Record confirmed decision, reason and relevant remaining conditions succinctly; dates should reflect actual confirmation, not invented chronology. Do not introduce databases or reorganize the project without a request.

Refresh live schemas before database writes. Verify the result and link the changed record. If a write fails, report it plainly and do not claim completion. The artifact catalog is an index of this agent; it is separate from Room and must not duplicate the behavioral definition.
